# Vault·It — Personal Net Worth OS

> *"Your financial blueprint. Built in public. Owned by you."*

**Alpha v0.3.1** — Single-file web app. No backend. No login. Works offline.

## Live
**https://vault-it.ptlive.design**
*(Fallback: https://fetapit.github.io/Vault-It/)*

## What It Does
House savings goal visualised as an isometric blueprint under construction. The more you save, the more the house gets built.

| Tab | What It Tracks |
|-----|----------------|
| Overview | Net worth KPIs, asset/debt entry, NW chart |
| House Builder | ISO house progression, deposit target |
| Debt Tracker | Snowball planner, interest calculations |
| Journey Map | FIRE roadmap, FI milestones |
| Entrepreneur | Business income streams *(Pro — coming soon)* |
| Skills | Skill tree, XP, level progression |

## Tech
Pure HTML/CSS/JS · SVG ISO renderer · localStorage only · GitHub Pages
