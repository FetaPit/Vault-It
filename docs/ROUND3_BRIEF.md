## B. As a fintech developer: data and disclosure brief

- **Forecast (1).** A projection is only as honest as its stated basis. Say in plain words: it is a straight line from the user's own recent trend, it assumes no investment returns, no inflation and no change in income or debts, and it is not a prediction. Keep "Not regulated by the FCA. Not financial advice." on the same card. Never show a forecast from fewer than two data points.
- **Debt (3, 4).** "Paid off" must mean principal actually cleared against a known starting balance. Where the starting balance was never recorded, show the remaining balance only and offer to record it, rather than guessing. Red is for money owed, green for money cleared; keep those meanings consistent with the colour code phase.
- **Market value (8).** Every live figure carries its source and timestamp. A value without a source is manual and labelled manual. Histories are the user's own data, stored on their device and in their cloud copy like everything else; no third party receives what they own. Do not call anything an appraisal or a valuation for sale purposes.
- **Crypto (10, 11).** Prices from CoinGecko are indicative spot prices in GBP, not an exchange quote; say "indicative" and show the age. Holdings are self-reported; we do not read exchange accounts. Show quantity, price and value separately so the user can check the arithmetic. Rounding: quantity to the token's precision (up to 8 places), value to the penny.
- **Privacy notice.** Nothing new is needed if only CoinGecko and the existing metals feed are used; if any other host is added, the notice is updated first and `tests/test_beta_client.js` is the gate.
- **Inventory and liabilities (12 to 14, 18).** A user's photos and 3D models are personal data; they stay on the device and in their own cloud row, and the expanded tile showing them (13) is a correctness bug to fix, not a feature.
- **Ledger (20).** One ledger, one set of numbers: every line must equal what the tab it came from shows, to the penny, in the same currency and at the same moment. If a value is stale (for example a live price older than a day) the ledger line says so.
- **Marketing copy.** None of these changes introduces claims, testimonials, scarcity or reference prices. Prices on screen stay what Stripe charges.
